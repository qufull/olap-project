# Спецификация дашборда Metabase: «Яндекс Доставка — Executive & Ops Monitor»

**Лабораторная работа:** З10. Дашборд Metabase  
**BI-платформа:** Metabase v0.52 (Docker, порт `3000`)  
**Источник данных:** Серверная аналитическая СУБД **ClickHouse** (`yandex_dw`), порт `8123`  
**Каталог SQL виджетов:** [`_stand/dashboards/`](.)

---

## 1. Концепция и назначение дашборда

Дашборд предназначен для топ-менеджмента и операционных директоров Яндекс Доставки.  
Он объединяет:
1. **Финансовый контур (Executive KPI):** валовой оборот (Net GMV), комиссию платформы (Take Rate) и фонд оплаты курьеров.
2. **Динамический контур (Trends):** дневной оборот по тарифам (Экспресс, Стандарт, Эконом), рассчитанный на базе высокопроизводительной **сводной таблицы З09** (`agg_daily_district_tariff`).
3. **Продуктовый контур (Unit Economics):** прибыльность кухонь и их ранги в структуре выручки.
4. **Логистический контур (Operations & SLA):** влияние погодных катаклизмов и часов пик на динамический спрос (Surge) и опоздания.

## 2. Архитектура подключения Metabase к ClickHouse

```text
[ Metabase BI Container ] (:3000)
         │
         │ HTTP / Native Port 8123
         ▼
[ ClickHouse Server Container ] (:8123 / :9000)
         │
         ├── yandex_dw.fact_orders (600,000 строк)
         ├── yandex_dw.agg_daily_district_tariff (13,140 строк — сводка З09)
         └── yandex_dw.dim_* (справочники)
```

### Параметры подключения в Metabase (Admin -> Databases -> Add database):
* **Database type:** `ClickHouse` (официальный драйвер `metabase-clickhouse-driver`);
* **Host:** `clickhouse` (внутри Docker сети) или `localhost` (при локальном запуске);
* **Port:** `8123` (HTTP интерфейс);
* **Database name:** `yandex_dw`;
* **User:** `default`;
* **Password:** *(пусто)*.

## 5. Глобальные фильтры дашборда

Дашборд снабжён двумя связанными переменными фильтрации:
1. **`{{district}}` (Район города):**
   * Тип: Field Filter (выпадающий список строк из `dim_districts.district_name`).
   * По умолчанию: *Все районы*.
2. **`{{date_from}}` и `{{date_to}}` (Временной период):**
   * Тип: Date Filter (календарный пикер от и до).
   * По умолчанию: *Весь аналитический год* (`2025-10-01` — `2026-09-30`).

Все 4 виджета корректно реагируют на изменение этих параметров благодаря синтаксису опциональных фильтров `[[AND ...]]` Metabase.
