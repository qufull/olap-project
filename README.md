## Архитектура модели данных (Star Schema)

- **Таблица фактов (Grain):** `fact_orders` — одна строка = один оформленный клиентский заказ (1 000 000 строк).
- **Справочники (Измерения):**
  - `dim_users` — клиенты сервиса (100 000 записей).
  - `dim_restaurants` — заведения и типы кухонь (250 записей).
  - `dim_couriers` — курьеры и тип транспорта (800 записей, кандидат на SCD2).
  - `dim_date` — календарное измерение (366 дней).
- **Главная метрика (Net GMV):** Выручка по доставленным заказам = **`79 143 059.95 BYN`** (899 940 выполненных заказов).

## Быстрый старт

### 1. Генерация данных (при необходимости перегенерации или изменения объема)

### 2. Сборка витрины DuckDB
```bash
python _stand/scripts/build_duckdb.py
```

### 3. Запуск аналитических запросов
```bash
python _stand/scripts/run_analytics.py
```
